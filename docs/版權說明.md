## 幾件關於著作權的事實（作者自己也該知道）

### 1. 著作權是自動產生的，不需要登記

我國著作權法採「創作保護主義」——作品完成的那一刻，著作權就成立了。
台灣自 1998 年起已**廢止著作權登記制度**，智慧財產局不辦理著作權註冊。
所以不存在「去登記才有版權」這回事，也不要相信任何說能幫你「登記著作權」的收費服務。

### 2. 著作人格權永遠是你的，不能讓與

著作權分兩塊：

| | 內容 | 能不能給別人 |
|---|---|---|
| **著作人格權** | 公開發表權、姓名表示權、禁止不當改變（同一性保持權） | **不得讓與、不得繼承** |
| **著作財產權** | 重製、公開傳輸、改作、散布、出租等 | 可授權，也可讓與 |

意思是：就算將來把財產權整包賣給出版社，「這是誰寫的」這件事，法律上永遠是你。
別人把你的作品改得亂七八糟並掛你的名，你仍可主張人格權受侵害。

### 3. 著作權保護「表達」，不保護「點子」

這是最容易誤解的一點，也是必須誠實講的：

**受保護的**：你寫下的具體文字、對白、段落安排、具體到足以識別的角色塑造。
別人整段複製、換幾個詞重貼、翻譯後發布——都是侵權。

**不受保護的**：「一把會吐槽的 AI 佩劍」這個概念、「劍關」這種決鬥制度的抽象構想、
「主角被誤會走火入魔」這種橋段。別人用同樣的點子，自己從頭寫一部完全不同的作品，
法律上不構成侵權。

對創意本身，實務上真正有效的保護是三件事：

1. **先發布、留下時間紀錄**——誰在先，一目了然
2. **把設定做深做厚**——抽象點子擋不住，但「劍關表關裡關雙層判定 + 二階段天雷縫隙 +
   劍匣強制中止」這種具體到骨架的體系，抄的人只要照搬就是抄表達，不照搬就寫不出同樣的東西
3. **累積辨識度**——大家先在你這裡看過，後來者反而像模仿

### 4. 書名不受著作權保護

「劍人」這兩個字本身不是著作。如果之後要當成 IP 經營（周邊、影視、系列作），
真正能擋別人用同名的是**商標**，不是著作權。可向經濟部智慧財產局申請，
相關類別大致是第 16 類（書籍印刷品）與第 41 類（娛樂、線上出版）。
不急，但如果哪天作品紅了，這件事要趁早做。

## 這個倉庫本身就是證據

Git 的每一個 commit 都記錄了**內容、時間、作者**，且無法在不留痕跡的情況下竄改歷史。
GitHub 的公開推送紀錄則提供了第三方的時間佐證。

換句話說：**「這段文字在某年某月某日就已經存在，且出自我手」——這件事本倉庫已經自帶證明。**
這比多數作者的處境好很多。

想再加強的話，可以做這幾件事（依成本由低到高）：

- **打 tag 發 Release**——為每個階段的完整版本留一個不可變的快照點
- **GPG 簽章 commit**——commit 上會顯示 Verified，證明確實出自你的金鑰
- **公證**——對法院所屬民間公證人辦理著作物認證，取得公證書（有費用，證據力最強）
- **美國著作權局登記**——只有打算在美國提告求償時才需要，一般不必

## 發布到其他平台之前，請先做這件事

**看清楚平台的服務條款。** 有些平台（尤其是網文站、部分 MCN 合作）的條款會要求：

- 取得作品的**獨家授權**，或
- 取得**可轉授權、可改作的廣泛授權**，或
- 主張平台對內容有**優先簽約權**

這類條款可能與本倉庫的 CC 授權衝突，也可能讓你在不知情的狀況下交出改編權。
簽之前一定要看第一段和「授權」那一節。

**建議的發布順序**：先在本倉庫 commit → 再發到其他平台。
這樣任何爭議發生時，首發紀錄永遠在你自己手上。
