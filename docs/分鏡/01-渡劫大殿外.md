## SB-01-A

| 欄位 | 內容 |
|---|---|
| **位置** | 置底 |
| **鏡頭目的** | 讓讀者一眼看懂「大師兄真的動手了，而且被一個更高的力量擋下」。同時這是全書第一次四人同框——順便完成角色介紹 |
| **揭示邊界** | 師父可以出現（他登場正是本章的翻轉，所以這格只能置底）。不得出現劍關、光柱、龍境門的任何元素 |
| **景別・機位・視線** | 中景群像／略低機位／斜四十五度三分之二側面。四人同框，視線焦點在半空中的劍尖 |
| **凍結瞬間** | 大師兄的劍尖停死在半空、被無形劍氣頂住，火花**正從接觸點往外炸開、還在擴散**。師父兩指剛從劍指姿勢放下，手還沒收到袖裡。男主角側身後仰躲了半步。小師妹半躲在他身後 |
| **資產綁定** | C01 + C02（燈：青）+ C03（持劍前推）+ C04（半躲）+ C05（右後方）@ S01。光源：左上方冷色日光 |
| **排除項** | 光柱、龍紋刻痕、任何文字、現代物件 |

### 為什麼是 1 格

本章的節奏是「挑釁 → 動手 → 被制止 → 吵回去」，只有「被制止」那一瞬同時滿足鏡頭目的與角色介紹。
其餘全是對白，交給文字。
