# 角色設定

> 這份文件是寫作時的對照表，用來避免稱呼與排行前後矛盾。內容僅記錄正文已寫出的資訊。

## 本門

### 師父
掌門，說話慢、愛摸鬍子。聽不懂徒弟的現代用語（「辣死賴」），但不執著名義。
知道劍匣強制中止劍關這件事——而且知道「那個劍匣還在」。

### 大師兄　秦飛羽
- 佩劍：**天羽劍**
- 招式：天羽擊、雙羽擊
- 認定三師弟走火入魔，一直想「疏通他的經脈」
- 在等師父教完《萬仙訣》才有把握贏三師弟——這件事被佩劍當眾抖出來

### 二師兄
**尚未登場。** 但門僮的稱呼體系裡確實存在，所以男主角排行第三。

### 三師兄（男主角／吾名）
- 佩劍：**佩劍**（就叫佩劍，沒有名字）
- 招式：御劍陣、御劍陣 2（劍分形）
- 全宗門眼中的走火入魔患者，因為他整天跟劍講話
- 入關宣告：「吾名：吾名！劍：劍！」——啟動指令是他自己設定的，要對佩劍比愛心
- 教門僮講英文（結果門僮學到的是 bitch）

### 小師妹
- 叫男主角「寶寶」
- 隨身帶著男主角送的手帕
- 熟知劍關規則，第四章當眾把規則講給對手聽

### 門僮
最小的弟子，扶師父回殿、在遠處看劍關。稱男主角為「三師兄」、小師妹為「師姐」。
負責觀眾視角的提問——劍關規則大多透過他跟師父的對話說明。

## 化境宗門・龍境門

### 宗主
真正的目的不是贏劍關，而是**採集樣本**。
運劍互擊後察覺男主角的佩劍「藏著某種莫名的靈動之力」。
最後一句：「不會太久的。」

### 龍傲天
- 佩劍：**傲天劍**
- 招式：天龍斬、天龍變形斬、崩山勁、聚龍臨界／聚龍掌
- 打法：在裡空間談判休兵、再偷襲——大師兄就是這樣輸的
- 敗戰後盯了男主角一時半刻才轉身離開

### 龍境門使
數名，抬劍匣、負責在敗局時拋出劍匣強制中止劍關。

## 用語

一律使用：**佩劍**（非「配劍」）、**師父**（非「師傅」）、**門僮**（非「道童」）、**鏡像**（非「境像」）、**裡**（非「裏」）。
