# 純文字入口與機器可讀端點

> 技術文件。給要把全文餵給工具、爬蟲或 AI 的人，以及維護這個倉庫的人。
> 一般讀者請走[線上閱讀](https://ruindorm.github.io/jianren/)。

## 端點

| 用途 | 網址 |
|---|---|
| 整本全文，一個檔 | `https://ruindorm.github.io/jianren/full.txt` |
| 單章 | `https://ruindorm.github.io/jianren/txt/ch01.txt`（`ch00` 起） |
| 設定集 | 同目錄下的 `characters.txt`、`world.txt`、`foreshadowing.txt`、`license-notice.txt` |
| 機器可讀索引（[llms.txt 慣例](https://llmstxt.org/)） | `https://ruindorm.github.io/jianren/llms.txt` |
| 網站地圖 | `https://ruindorm.github.io/jianren/sitemap.xml` |
| 抓取規則 | `https://ruindorm.github.io/jianren/robots.txt` |

簡體與英文把語言代碼加在路徑中間：
`…/jianren/zh-Hans/full.txt`、`…/jianren/en/txt/ch01.txt`

## 備援網域

若對方連 `github.io` 也擋，倉庫根目錄放了同樣的純文字全文，走 `raw` 網域：

- `https://raw.githubusercontent.com/ruindorm/jianren/main/full.txt`
- `https://raw.githubusercontent.com/ruindorm/jianren/main/full-zh-Hans.txt`
- `https://raw.githubusercontent.com/ruindorm/jianren/main/full-en.txt`

## 為什麼需要這組入口

直接把 GitHub 的檔案網址（`github.com/…/blob/main/src/01-渡劫大殿外.md`）交給工具，常常讀不到，原因與權限無關——本作品全程公開：

1. 不少 AI 的抓取政策直接擋掉整個 `github.com` 網域（回報 `LIVE_CRAWL_POLICY_BLOCKED`）
2. GitHub 的檔案瀏覽頁靠 JavaScript 渲染，只抓 HTML 的工具讀不到正文
3. 中文檔名會被編碼成 `01-%E6%B8%A1%E5%8A%AB%E5%A4%A7%E6%AE%BF%E5%A4%96.md`，部分工具處理不了

因此另外備了一組**純文字、免 JavaScript、路徑全 ASCII** 的鏡像。

## 維護須知

這些檔案全部由 GitHub Actions 在每次章節更新後自動重建，與正文永遠同步。

**根目錄的 `full*.txt` 不要手動編輯**，正文請改 `src/`。
