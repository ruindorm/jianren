# 世界觀：劍關規則

## 劍關開啟時

1. 地板震動、狂風大作，天空裂出**異次元空間**
2. 在場所有人的思考與動作被**強制緩速**
3. 兩條**光柱**貫穿天際線，各自封入一把本尊劍，筆直插在地上
4. 雙方意識被**鎖進自己的劍**中，肉身留在原地，眼露紅光——師父稱之為「被質押在場上」

## 宣告格式

> 吾：〈姓名〉，劍：〈劍名〉，**開啟劍關**！（挑戰方為「進入劍關」）

男主角的版本是「吾名：吾名！劍：劍！**接替入關**！」——並且需要對佩劍比愛心才會啟動。

## 交錯的核心設計

光柱掃描讀取兩把劍後，會向兩人射出**對方那把劍的鏡像**。

也就是說：**你拿著的是敵人的劍，操控它去攻擊敵人自己的本體劍。**

## 勝負判定

師父的說法：摧毀對手光柱裡面的劍，或者把劍打出光柱外面，就算贏了。

劍受到劍氣衝擊會被逐吋擊出（傲天劍曾被擊出半吋）；接關時會重置回初始深度。

## 表關與裡關

| | 表空間（劍關內） | 裡空間（異空間） |
|---|---|---|
| 誰在打 | 兩把鏡像劍 | 兩人的意識 |
| 觀眾看得到 | 看得到 | 看不到 |
| 作用 | 直接決定勝負 | 輸贏決定**光柱護罩強度** |

大師兄的結論：**只靠劍是不行的。**

裡關可以談判——龍傲天正是用「休兵、讓劍決勝負」的提議騙過秦飛羽，然後偷襲。

## 二階段：天雷降世

光柱開始變色即為預告。大師兄的說法：進入二階段的瞬間，**表、裡兩關會出現暫時的縫隙**。

縫隙可以被外力利用：龍境門事先刻在前殿的龍紋，就是在這一刻聚成龍形、穿過縫隙貫入龍傲天體內（聚龍臨界）。

天雷本身也能被引導——男主角的劍分形直接把天雷連通到對手光柱，形成無法防禦的打擊。

## 挑戰的代價

小師妹講出來的規則：

- **人劍分離質押**
- **劍招明示**
- 輸家要在自己的劍關**立下敗戰恥辱**

所以通常不同宗門不太隨便挑戰對方的劍關。

## 強制中止

**劍匣**可以在結算完成前吸回本尊劍，強制中止劍關，雙方意識立即回歸。

師父見到時的反應：「果然出現了……沒想到那個劍匣還在。」
