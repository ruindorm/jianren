# 分鏡提示詞規範

> 章節插圖的分鏡怎麼拆、提示詞怎麼寫。**這是製作文件，不上讀者網站**（已加入 `build-site.sh` 的排除清單）。
> 生成參數、成本、壓縮流程見〈[圖片生成](./圖片生成.md)〉，這裡只管「畫什麼」。

分章的分鏡單放在 `docs/分鏡/`，一章一檔，檔名對齊 `src/`。

---

## 0. 核心規則

**誰在說話，畫面就以誰為主體。** 台詞換，畫面換。旁白就畫旁白寫的東西，描寫主體換了畫面也跟著換。
佩劍說話的時候，主體就是佩劍。

**畫面永遠不含文字。** 沒有對話框、沒有招式名、沒有匾額。
台詞用程式合成在畫面下方的字幕條上——**圖片只負責圖片**。

這兩條決定了以下所有規則。

## 1. 四個單位：節拍、串、頁、機位

分不清這四個，後面全部會亂。

| 單位 | 是什麼 | 數量 |
|---|---|---|
| **節拍** | 正文的一句台詞或一段旁白。**內容單位** | 337 |
| **串** | 連續 1–6 頁，合起來是讀者感覺到的**一個**動作。**規劃單位** | 約 120 |
| **頁** | 讀者點一下看到的東西 ＝ 一張圖 ＋ 0 或 1 條字幕。**呈現單位** | 約 538 |
| **機位** | 攝影機的一個架設位置。**生產單位** | 約 90 |

**頁 ≠ 節拍。** 頁比節拍多——多出來的是**靜格**（無字幕的頁）。

### 串：真正的規劃單位

**不要一頁一頁設計，要一串一串設計。**

靜格 0.3 秒翻一頁，連點三到六下大約 1–2 秒——那正好是**一個知覺瞬間**的長度。
所以連續三到六頁在讀者腦中不是「六張圖」，是**一件事**。

這是規劃層級的分界：538 頁沒有人排得動，**120 串排得動**。
而且用串來想，才問得出對的問題——不是「這裡要幾張圖」，而是「**這一串要讓讀者感覺到什麼**」。

**鐵則：每一串都要寫得出目的。寫不出來就整串砍掉。**
不是每一頁都要有目的（靜格本來就沒有獨立資訊），是**每一串**要有。

### 八種串型

| 串型 | 頁數 | 目的 | 出口 |
|---|---|---|---|
| **對話串** | 1–2 | 一句台詞，可能帶一個反應 | 下一句 |
| **重擊串** | **1** | **一張無字幕的圖獨自成串**——硬停 | 反應或沉默 |
| **巡場串** | 3–5 | **讓讀者感受空間的規模與氣氛**，橫向掃過，不逼近 | 進入場景 |
| **推進串** | 3–6 | 由遠而近逼向主體，交出注意力 | 台詞頁 |
| **拉開串** | 2–4 | 反向，從特寫退到全景 | 收場或換場 |
| **動作串** | 3–5 | 把一個動作拆開，製造速度 | 結果頁 |
| **爆點串** | 5–8 | 墊 → 落 → 餘震 | 台詞回來 |
| **對峙串** | 4–8 | 正反拍交替、逐漸加快 | 誰先動 |

**重擊串是唯一一種「一頁自成一串」。**
它跟對話串裡的單頁不同：那是一句話，這是一個**停**。
一張無字幕的圖獨佔一串，前後都不接同型的東西，讀者會撞上它——
揭示、死亡、第一次看見某樣東西，用這個。

用多了就沒有重量。全書預計不超過八處，第十二章「傲天劍被轟出光柱」那張判定格是標準用法。

**巡場串與推進串不一樣，最容易混。**

- 推進串是**逼近一個主體**，鏡頭愈來愈小，終點是臉
- 巡場串是**掃過一個空間**，景別可以一直維持大，終點是「我知道這裡有多大」

第四章走進被刻滿龍紋的前殿、第十五章主殿融解成重影空間、第二十二章風冥洞——
那些要的是巡場串，不是推進串。**用錯就會變成「一直盯著一個人看」，空間感反而沒了。**

巡場串的內部順序建議：全景 → 局部細節 → 另一個局部 → 拉回全景。
中間那兩個局部是氣氛的來源（一根刻痕、一道光、一片剝落），
最後拉回全景讓讀者把細節裝回空間裡。

### 一章長什麼樣

章 ＝ 一串接一串，不是一頁接一頁。第八章 27 頁其實只有 8 串：

```
串 1  對話串   1 頁    C01 宣告
串 2  對話串   2 頁    佩劍插嘴（＋全場轉頭的反應）
串 3  對峙串   4 頁    小師妹／龍傲天／門使／大師兄，四個錯愕輪替
串 4  爆點串   7 頁    三墊 → 愛心 → 三收        ★ 全章的存在理由
串 5  對話串   2 頁    「…………」＋沉默續延
串 6  動作串   4 頁    光柱降下、空鏡、紅光眼、換劍
串 7  對話串   5 頁    御劍陣、劍氣、重複、僵住、說不出話
串 8  拉開串   2 頁    拉遠收束 → 切 S05 師父
```

**這樣才排得動。** 寫分鏡單時先排串，再展開成頁。

### 靜格：為什麼畫面數量可以大膽

關鍵在於**兩種頁的閱讀時間差了一個數量級**：

| | 讀者停留 |
|---|---|
| 有字幕的頁 | 1–3 秒（要讀完字） |
| **靜格（無字幕）** | **約 0.3 秒（一秒翻完）** |

所以靜格在閱讀時間上幾乎免費，卻能完全控制節奏。
**這是漫畫最重要的工具，不是額外的裝飾。** 手翻書就是這個原理的極端版本。

「一句台詞配一張圖」在資訊上是對的，在**節奏**上是貧乏的——
所有頁的權重一樣，讀者感覺不到快慢，笑點沒有停頓，打鬥沒有速度。

### 靜格的六種功能

不是無謂增加畫面。每一個靜格都要能講出它屬於哪一種：

| 種類 | 幹嘛用的 | 例 |
|---|---|---|
| **停頓格** | 笑點或衝擊**之前**的空白 | 第八章比愛心之前，插一格他深吸一口氣 |
| **反應格** | 聽的人的臉 | 比愛心之後，全場石化 |
| **插入格** | 手、眼睛、物件的特寫，建立注意力 | 大師兄的手正握緊劍柄 |
| **空鏡** | 場景、天空、環境。換場與降速 | 第十二章打完之後的空蕩廣場 |
| **分解格** | 一個動作拆成連續數格，製造速度 | 天龍斬的起手／中段／命中 |
| **重複格** | **同一張圖再放一次**，時間凝滯 | 「…………」的沉默拉長 |

**重複格成本是零**——它重用同一個檔案，只是多一頁。這是最便宜的節奏工具，不要客氣。

### 推進梯：靜格的成套用法

連續數個靜格由遠而近逼向主體，最後一頁交給台詞。這是**開場用的重武器**，
效果很強，但有三個地方會做壞。

**一、不能只變距離，角度也要動。**
同一個角度單純推近，在剪接上叫**跳接**——讀者看到的不是「鏡頭走近」，是「畫面抽動」。
規則是每一階**同時**改變景別與角度（一般抓 30 度以上）。

```
✗ 正面遠景 → 正面全景 → 正面中景 → 正面近景 → 正面特寫      跳接五次
✓ 高角遠景 → 側前全景 → 正面中景 → 側後近景 → 仰角特寫      每階都換
```

**二、景別階梯要跳級。** 一階一階乖乖走完六級會很機械。偶爾跳一級，
例如遠景直接切中景，讀者反而感覺得到「被拉進去」。

**三、梯子的最後一階，要停在台詞需要的景別。**
推到只剩眼睛才開口，那句台詞就沒有畫面可用了。
**梯子停在對話要用的那一級，或再寬一級。**

#### 一張圖切出整座梯子

推進梯是全書**最容易看出漂移**的地方——連續五頁同一個人，臉只要變一次就穿幫。
分五次生成，就是給自己五次漂移機會。

解法：**用 2K 生一張，裁切出其中幾階。**

- 裁切不縮放，像素格完全一致，**接得天衣無縫**
- 同一張圖裁出來的階，人物**物理上不可能漂移**
- 2K/low 一張，比拆成三張 1K 貴不了多少，換到的是零漂移

限制：裁切只能變近，**不能變角度**。所以實務上是混的——

```
第 1 階  2K 母圖的全幅
第 2 階  2K 母圖裁切          ← 免費，零漂移
第 3 階  新生成（角度換邊）    ← 這裡打破跳接
第 4 階  第 3 階的裁切         ← 免費，零漂移
第 5 階  新生成（仰角特寫）
```

五階只生成**兩張**。裁切的階天然接得順，新生成的階負責換角度。

#### 什麼時候值得用

五階推進大約吃掉讀者 1.5 秒，是很大的節奏投資。只給**需要重量的開場**：

| 適合 | 不適合 |
|---|---|
| 第五章 劍關開啟（世界規則第一次展開） | 第二章（兩個人繼續吵架） |
| 第十五章 劍關重影（師父的過去揭幕） | 第三章（門僮跑進來報信） |
| 第二十二章 風冥洞（八十年前的收束） | 任何只是換個人講話的地方 |

**梯子用多了就不叫重武器了。** 全書預計不超過六處。

### 節奏配額

靜格數量 ≈ 節拍數 × 係數。這是起點不是上限，實際依戲決定：

| 章型 | 係數 | 為什麼 |
|---|---|---|
| 對話章 | 0.2 | 靠 shot／reverse 本身的節奏就夠 |
| 場面章 | 0.4 | 需要空鏡建立空間 |
| 打鬥章 | 0.8 | 分解格是速度感的唯一來源 |

全書估算：**337 節拍 → 201 靜格 → 538 頁**（＋60%）。

成本沒有等比增加，因為靜格大多不是新圖：

| 來源 | 佔比 | 張數 | 成本 |
|---|---|---|---|
| 重複格（重用同一檔案） | 30% | 60 | **$0** |
| 反應／停頓（既有機位新變體） | 45% | 90 | 用遮罩局部重繪 |
| 插入／空鏡／分解（全新） | 25% | 50 | 新生成 |

全書總計約 **315 張圖、$1.13**。頁數多了 60%，成本只多了不到一倍。

## 1b. 生產單位是機位，不是句子

全書 **337 個節拍**（252 句台詞 + 85 段旁白）。一句生一張就是 337 張獨立生成的圖，
以 $0.0036 算是 $1.21——錢從來不是問題，**一致性才是**。337 張各自生成，角色必然漂移。

Sitcom 的解法就在 sitcom 本身：多機作業的攝影棚只架四台固定攝影機，整季重複使用。
《劍人》的 (場景 × 說話者) 組合只有 **55 組**，正規化重複標籤後約 40 組。

| 拆法 | 生成張數 | 成本 | 一致性 |
|---|---|---|---|
| 一句一張 | 337 | $1.21 | 必然漂移 |
| **機位 × 變體** | **約 90** | **$0.32** | 同一機位永遠是同一張圖 |
| 旁白格（各自獨立） | 85 | $0.31 | 事件性畫面，本來就該獨立 |

**所以：一句台詞綁定到一組「機位＋變體」，同一組合重複出現就重用同一張圖。**
大師兄在第一章講 7 句，可能只用掉 2 張圖。

這不是省錢，是 sitcom 的節奏本身——觀眾看到同一個角度回來，就知道「換他講話了」。

## 2. 產出規格

### 畫布

生成 **16:9**，字幕條佔畫面下方 **1/4**。

```
┌────────────────────────┐
│                        │
│                        │  ← 16:9 生成畫面，佔 3/4
│                        │
├────────────────────────┤
│  台詞放這裡            │  ← 字幕條，佔 1/4
└────────────────────────┘
        整體 4:3
```

**圖 16:9 佔 3/4 的話，總畫布必定是 4:3。** 這不是湊出來的：
總高 ＝ 圖高 × 4/3 ＝ 寬 × 3/4，1536×864 的圖配 288px 字幕條就是 1536×1152。

| 項目 | 值 |
|---|---|
| 生成比例 | 16:9 |
| 品質 | `quality=low` / `resolution=1K`，固定 |
| 最終比例 | **4:3**（圖 3/4、字幕 1/4） |
| 字幕條底色 | `#12121a` |
| 字幕文字 | `#f2f2f2` |
| 行數 | 最多 3 行，填滿字幕條的 82% |
| 字級 | 字幕條高 ÷ 3 ÷ 1.35，1536 幅寬下約 57px |
| 單行上限 | 23 全形字（容量 69 字） |

### 為什麼是 1/4 而不是更窄

拿全書 337 拍實測，字幕條寬窄直接決定有多少拍塞得下：

| 字幕條 | 容量 | 字級（1536 幅寬） | 放不下 |
|---|---|---|---|
| 15.6%（3:2） | 2 行 × 30 ＝ 60 字 | 42px | 5 拍 |
| **25%（4:3）** | **3 行 × 23 ＝ 69 字** | **57px** | **0 拍** |

**1/4 同時解決了「字要大」和「長旁白塞不下」**，字級還大了 36%。
節拍中位數只有 19 字，多數時候一行就夠——3 行是為了第四章那種 67 字的長段留的餘裕。

**合成只能 pad，不能 scale。** 縮放會糊掉像素硬邊，整張變爛泥。

### 命名

| 用途 | 路徑 |
|---|---|
| 機位原圖 | `assets/ch/{場景}-{機位}-{變體}-raw.png`　例：`s01-a-1-raw.png` |
| 旁白原圖 | `assets/ch/n{章}{序}-raw.png`　例：`n05c-raw.png` |
| 合成輸出 | `assets/ch/ch{章}-{節拍序號}.webp`　例：`ch01-07.webp` |

檔名一律 ASCII——GitHub Release 會剝掉非 ASCII 字元。

### 節拍編號

`src/` 章節檔裡，扣掉標題、分隔線、導航列、footer 之後，
**每一行台詞或每一段旁白，依序編號**。這是分鏡單與字幕合成共用的座標。

**分鏡單不複寫台詞原文**，只寫序號與前十個字的摘要。
原文的唯一權威是 `src/`——複寫就會在你改稿之後對不上。

## 4. 資產編號

跨機位一致性靠編號，不靠形容詞。分鏡單寫 `C01`，不要重寫「穿深色勁裝的年輕劍客」——
重寫就會漂移。

### 角色

| 編號 | 角色 | 三個視覺錨點（提案，**待作者確認**） |
|---|---|---|
| C01 | 吾名（男主角・三師兄） | 深色勁裝袖口捲起／腰間一條隨性紅繩／鬆散髮髻加幾綹碎髮 |
| C02 | 佩劍 | **無護手，柄與刃以一塊幾何斜面接合**／**一道直溝槽貫穿全刃**／**斜切刃尖**（劍身永遠浮空，不插地） |
| C03 | 大師兄　秦飛羽 | 一絲不苟高馬尾／白底藍緣長袍／永遠站得筆直 |
| C04 | 小師妹 | 淺色短打加長飄帶／腰間香囊／手上常有一方手帕 |
| C05 | 師父（元平・現在） | 灰白長鬚／寬袖灰道袍／慣性動作是撫鬚 |
| C06 | 門僮 | 矮一截的少年／抱著掃帚或藥箱／眼睛總是睜很大 |
| C07 | 龍傲天 | 黑金龍紋長袍／高冠／下巴微抬 |
| C08 | 龍境門使 | 同款黑金制服／面覆／群體同形，不給個人特徵 |

| C10 | 元平（八十年前） | 與 C05 同鼻樑同眉形／黑髮／素白劍服 |

>
> 佩劍講 26 句話，是全書出現次數最多的單一物件。在 16-bit 像素風、1K/low 之下，
> **能穩定重現的只有剪影與大線條**——小裝飾（一顆寶石、一枚符號、細紋飾）
> 只佔幾個像素，每次生成都會長不一樣，是漂移的主要來源。
>
> 所以三個錨點全部下在輪廓上：**沒有護手**（柄與刃靠一塊幾何斜面接合）、
> **一道直溝槽貫穿全刃**、**刃尖是斜切面而非對稱尖**。
> 這三件事在縮圖大小都看得出來，而且模型每次都抓得到。
>
> **不要用會閃的東西表達狀態。** 靜態圖裡沒有「閃爍」這回事——
> 那是一個渲染不出來的狀態，寫進規格只會製造無法驗收的格子。

### 佩劍怎麼在沒有表情的情況下演戲

它不需要。一支手機也沒有指示燈，照樣能講話——**演戲的是它周圍的畫面，不是它自己**。
變化來自這四項，全部都是實體的、畫得出來的：

| 手段 | 例 |
|---|---|
| 劍身傾角 | 水平＝待機／斜指主人＝插嘴／垂直＝正經 |
| 與主人的相對位置 | 浮在肩側／擋在身前／被冷落在畫面邊緣 |
| 環境反應 | 塵埃被劍氣推開、反光的方向、劍身周圍的空氣扭曲 |
| 景別與角度 | 貼臉特寫＝逼問／遠景孤零零一把＝被無視 |

**造型語彙：石墨灰陽極處理金屬、啞光、幾何、流線、無紋飾、無有機曲線。**

這一點跟設定是對上的：整個修真世界是木、石、金、玉、有機曲線，
佩劍是唯一一件工業感的東西——**它看起來就不屬於這個世界，這正是「它是 AI」的視覺暗示**，
不需要靠一顆燈來說明。

### 場景

| 編號 | 場景 | 編號 | 場景 |
|---|---|---|---|
| S00 | 無場景（楔子） | S05 | 遠方觀戰處 |
| S01 | 渡劫大殿外 | S06 | 龍境門主殿 |
| S02 | 前殿（刻龍） | S07 | 本門主殿 |
| S03 | 劍關表空間 | S08 | 劍關重影空間 |
| S04 | 異空間（裡關） | S09 | 風冥洞深處 |

### 道具

| 編號 | 道具 | 編號 | 道具 |
|---|---|---|---|
| P01 | 天羽劍 | P05 | 光柱 |
| P02 | 傲天劍 | P06 | 龍紋刻痕 |
| P03 | 元劍 | P07 | 手帕 |
| P04 | 劍匣 | P08 | 金丹 |

**鏡像劍要標明。** 劍關的核心設計是「你拿著的是敵人的劍」，畫錯就毀了整個設定。
寫法：`P02鏡像`（龍傲天光柱裡的是本尊 `P02`，秦飛羽手上的是 `P02鏡像`）。

## 5. 走位圖與軸線

**這是新做法裡最容易搞砸、也最便宜就能做對的一步。**

一個場景開拍前先畫走位圖，定出 **180 度線**：所有機位都待在線的同一側。
定完之後，每個角色的**視線方向就固定了**——A 永遠看向畫右，B 永遠看向畫左。

```
S01 渡劫大殿外・軸線

            C05 師父
              ▲
              │
  C03 ────────┼──────── C01 + C04
 (看畫右)     │        (看畫左)
              │
  ════════════╧════════════  ← 180 度線，所有機位在線下方
```

沒有軸線，第一章那 17 句 shot／reverse 切下來，讀者會覺得兩個人在各自對空氣講話。
有軸線，就算連切 20 格也讀得懂誰在對誰講。

**角色移動位置就要重畫走位圖，並且補一張 master。** 第三章小師妹拉著男主角走出去，
軸線就換了，S01 的走位圖到此結束。

## 6. 機位表

從走位圖導出，一個場景一張。每個會說話的主體至少一個 clean single。

| 欄位 | 說明 |
|---|---|
| **機位 ID** | `S01-A`。場景編號加字母 |
| **主體** | C／P 編號 |
| **景別** | master／two-shot／single／CU／群像 |
| **視線方向** | 畫左／畫右／正面。**必須符合軸線** |
| **變體** | 這個機位需要幾種表演。變體用數字：`S01-A-1`、`S01-A-2` |

### 變體怎麼決定

**正文括號裡的動作提示，就是變體選擇器。**

> **男主角**：（得意）That's right！師妹你今天好香啊～
> **男主角**：（冷笑）幹架還要找理由？

同一個機位 `S01-C`，變體 1 ＝得意，變體 2 ＝冷笑。括號沒寫的就用中性變體。
**一個機位的變體不要超過 3 個**，超過就代表這個角色在這場戲裡情緒跳太多，回頭檢查是不是機位切錯了。

### 每個場景的必備機位

| 機位 | 什麼時候一定要有 |
|---|---|
| **master** | 場景第一格必須是 master。觀眾靠它建立空間，跳過就會迷路 |
| **single** | 每個說話的主體各一 |
| **two-shot** | 兩人有互動、有肢體接觸、或一人反應另一人時 |
| **群像** | `眾人` 說話時，以及需要交代全場反應時 |

**連續同一機位不得超過 2 句。** 第三句就要插進 two-shot、群像或反應格，
否則讀者會以為圖沒換。這是 sitcom 的節奏底線。

## 7. 旁白格

旁白**預設不重用機位**，各自獨立生成——它們是事件，不是對話。

例外：**旁白的主體正好是某個既有機位的主體時，重用該機位並新增變體。**
第十二章「眾人紛紛趕緊閉上眼睛」的主體就是群像，另外生一張全新的群像純屬浪費。

主體判定照字面走：

| 旁白原文 | 主體 |
|---|---|
| 「金屬撞擊，火花四起，大師兄的劍被一道無形劍氣擋下」 | 劍尖與火花（不是人） |
| 「傲天劍受到劍氣衝擊，被擊出半吋」 | P02 與 P05 的交界 |
| 「大師兄眼露紅光，意識已經被鎖在天羽劍中」 | C03 的眼睛 |
| 「一名帥氣男子從門使後方走出，龍境門使讓開一條路」 | C07 與讓開的 C08 |

**一段旁白描寫了兩個主體就拆成兩格。** 第五章「地板震動，狂風大作，天空出現了詭異的次元空間」
與「大師兄周圍出現了一股斥力，並有兩條光柱貫穿天際線」是兩件事，兩格。
編號用 `18a`／`18b`，字幕各自切開。

**極短的轉折旁白不另給格。** 「但是……」「同時間——」「然而」這種沒有主體的連接詞，
硬給一格會打斷前後的節奏。做法是併進前一拍的字幕，中間空兩格：`我們贏了！　但是……`

## 8. 硬規則

**一、主體＝說話者。** 沒有例外，除非用了下面的反應格機制。

**二、凍結瞬間，不是流程。** 一格是一瞬。不准「先……再……最後」、不准描述表情變化過程。
寫「火花正從接觸點炸開、還在擴散」，不要寫「兩劍相撞後火花四射」。

**三、運動中，不是擺拍。** 劍要劈到一半、光要灌到一半。已完成的死姿態會讓整章看起來像立繪展示。

**四、軸線不得跨越。** 同一場景內所有機位在 180 度線的同一側，視線方向固定。

**五、連續同機位不超過 2 句。**

**六、一格不得早於它的台詞。** 這格畫面只能包含這一句講完為止已經發生的事。
第八章「吾名：吾名！劍：劍！接替入關！」那一格**不准出現愛心**——愛心是三句之後的事。
連載的讀者是一格一格往下看的，早一格就是劇透。

**七、資產綁定用編號。** 機位表寫 `C01 + C02（斜指主人）@ S03`，提示詞正文才展開成英文，
且展開內容必須逐字對應第 4 節的錨點。

**八、排除項只擋當前風險。** 不要寫萬用禁詞長清單。第五章之前不可能有光柱，那就在第五章之前寫
`no light pillars`，之後就不用寫了。清單越長，模型越容易整段忽略。

**九、畫面永遠不含文字。** 招式名、匾額、地上刻的「到此一遊」全部不畫。
第四章那些刻痕畫成**抽象的龍形凹槽**。台詞一律走字幕條。

**十、相鄰兩頁必須有剪影級的差異。**

這條是整套靜格設計的**存活條件**，不是美學建議。

靜格的前提是「讀者花 0.3 秒看一眼」。但實際上**讀者的點擊速度不受我們控制**——
遇到無字幕頁，很多人會連點衝過去，一秒五下。
在那個速度下，兩張只差一點點的圖，讀者**什麼都沒看到**，那一串就等於不存在。

所以：**連續的頁之間，要有一眼就能分辨的輪廓變化。**

| ✗ 撐不住快速點擊 | ✓ 撐得住 |
|---|---|
| 同一個人同一個角度只換眉毛 | 換景別、換角度、換主體 |
| 兩張全景只差雲的位置 | 全景 → 局部特寫 |
| 光暈亮度差 10% | 光暈填滿畫面 vs 幾乎沒有 |

**重複格是這條規則的唯一豁免**——它本來就是同一張圖，讀者感覺到的是「時間停住」，不是「畫面沒換」。

推論：**讀者端也要設下限。** 分鏡閱讀器應該給每一頁一個最短顯示時間（約 120ms），
否則連點會直接跳過整串。這是閱讀器的事，但決定權在分鏡——
**如果一串禁不起被跳過，它就不該存在。**

### 反應不是例外，是靜格

先前這裡寫著「反應格是唯一的例外」——**那條規則作廢了**，因為靜格把矛盾解掉了。

原本的困境：最好笑的往往是聽的人，不是講的人（第八章比愛心，眾人石化的臉比他本人好笑），
所以想把那一句的主體換成聽眾。但那會破壞「主體＝說話者」。

有了靜格就不必二選一：

```
第 7 頁　有字幕　「吾劍啟動！」　主體 = C01（說話者，規則不破）
第 8 頁　靜格    全場石化        主體 = 聽的人（反應，一秒翻過）
```

**說話的頁永遠是說話者，反應自己佔一頁。** 規則保持純粹，喜劇效果反而更強——
因為反應變成獨立的一拍，而不是跟台詞擠在同一格。

## 9. 提示詞模板

正文用英文。像素風與攝影術語的英文語彙模型理解最穩，中文意圖寫在機位表就夠了。

```
{PREFIX}
[SHOT]     景別、機位、視線方向、構圖
[SUBJECT]  主體錨定，逐項對應資產表
[ACTION]   凍結瞬間，現在進行式
[SETTING]  場景與光向
Exclude:   排除項
```

### 鎖定前綴（`{PREFIX}`，逐字複製）

```
16-bit pixel art, SNES-era JRPG cutscene illustration, hard pixel edges,
no anti-aliasing, limited palette of about 24 colors, dithered gradients,
1px dark outlines on characters, 16:9 composition.
```

分鏡單裡一律寫 `{PREFIX}` 代替，生成時展開。**任何一格都不准改動它**——
它是全書視覺的唯一保證。要調風格就整本一起改，改完全部重生。

### 動作格加寫的五件事

打鬥格必須看得出這五件事，缺一張圖就會變成「兩個人在發光」：

1. **誰打誰、命中哪**——最高優先
2. **空間幾何**——相對位置、誰在前誰在後、光柱在哪邊
3. **重量感**——反作用力、衣袂鼓盪、重心崩潰
4. **層次**——地面／中段／騰空至少兩層，前／中／背景至少兩層
5. **代價**——破損、喘息、損傷痕跡

## 10. 字幕合成契約

圖片生成完全不管字幕。合成由 `tools/compose-subtitle.ps1` 負責：

```powershell
.\tools\compose-subtitle.ps1 -In assets/ch/s01-c-1-raw.png `
                             -Text '你才有病！你全家都有病！' `
                             -Out assets/ch/ch01-02.png
```

契約：

- 輸入 16:9 原圖，輸出 4:3（圖 3/4、字幕 1/4），**只 pad 不 scale**
- 文字用 `drawtext=textfile=`，不用 `text=`——避開 `：！～` 與中文的跳脫地獄
- 超過單行上限（23 全形字）就斷行，最多 3 行；還放不下就是台詞太長，回頭拆節拍
- **不放說話者名牌**。畫面已經指明是誰在講——這正是這套做法的價值所在，
  放了名牌等於承認畫面沒說清楚

### 網頁版不烤字幕

`compose-subtitle.ps1` 是給 **EPUB、社群貼圖、下載版**用的——那些場合字幕必須烤進圖片。

**網頁版把字幕用 HTML 疊在圖片下方，不要烤。** 理由是這個倉庫有三個語言版本：

| | 烤進圖片 | HTML 文字 |
|---|---|---|
| 圖片數量 | 337 × 3 語言 ＝ **1011 張** | **337 張**，三語共用 |
| 改錯字 | 重新生圖 | 改文字檔 |
| 可選取／可搜尋 | ✗ | ✓ |
| 爬蟲與 AI 讀得到 | ✗ | ✓（見〈純文字入口〉） |
| 字級隨螢幕縮放 | ✗ 固定像素 | ✓ |
| alt text | 要另外寫 | 字幕本身就是 |

三語共用同一批圖，這件事本身也在幫忙——同一個機位在三個語言版本裡是同一張圖，
視覺一致性不會因為語言而分岔。

## 11. 自檢清單

生成前：

- [ ] 走位圖畫了，軸線定了，這個機位在線的正確側
- [ ] 視線方向符合軸線
- [ ] 場景第一格是 master
- [ ] 沒有連續三句用同一機位
- [ ] 這格沒有包含它那句台詞之後才發生的事
- [ ] 有字幕的頁，主體就是說話者（**無例外**；要拍反應就另開一個靜格）
- [ ] 每個靜格都指得出它屬於六種功能的哪一種，指不出來就刪掉
- [ ] 每一串寫得出目的；相鄰頁之間有剪影級差異（重複格除外）
- [ ] 重複格確實重用了同一個檔案，沒有重新生成
- [ ] 主體描述逐項對應資產錨點，沒有臨時發明的特徵
- [ ] 鏡像劍標對了——誰手上拿的是誰的劍
- [ ] 排除項只有本格的實際風險
- [ ] 提示詞裡沒有任何要求畫文字的字眼

生成後：

- [ ] 畫面確實沒有文字（模型偶爾會自己加招牌）
- [ ] 合成用 pad 沒有 scale
- [ ] 同一機位的不同變體，角色沒有換人

## 12. 已知地雷

**佩劍不能插在地上。** 它是浮空的。第五章之後光柱裡插地的是本尊劍，那是另一回事——
畫錯會讓讀者以為佩劍下線了。

**「眼露紅光」只在意識被鎖進劍裡的時候。** 表空間的肉身才有紅光眼；
異空間（S04）裡是意識體，不畫紅光。這兩個空間的區別是全書最容易畫錯的地方。

**遠方觀戰處（S05）與表空間（S03）不同框。** 師父與門僮看得到劍關，但他們在遠處。
同框會讓讀者以為師父就站在旁邊沒出手。第六、九、十一章大量在這兩個場景之間切，
每次切換都要重新給 master。

**倒地的大師兄不能消失。** 第七章倒地、第九章才醒。中間幾章凡是 S03 的群像機位，他必須還躺著。

**八十年前的段落（15–23 章）不要換風格。** 想用褪色或單色調區分很自然，
但那會破壞「重影是即時投影、不是回憶」的設定。改用**冷色偏移**（整體偏青灰）就夠了。

**`吾名—劍版` 說話時主體是劍不是人。** 這幾句很容易誤畫成男主角在講話。
他的意識在劍裡，表空間的肉身站著不動、眼露紅光——主體是劍陣或光柱裡的劍。

## 13. 方法論來源

軸線、機位表與變體制度是 sitcom 多機作業的標準做法。
「先寫鏡頭目的、凍結瞬間、排除項只擋當前風險」來自 [`worldwonderer/drama-skills`](https://github.com/worldwonderer/drama-skills)。
第 9 節「動作格加寫的五件事」來自 [`CY-CHENYUE/martial-arts-director-cy`](https://github.com/CY-CHENYUE/martial-arts-director-cy)。
「運動中而非擺拍」與景別節奏來自 [`mwddmmde12-del/storyboard-artist`](https://github.com/mwddmmde12-del/storyboard-artist)。
C／S／P 編號法來自 [`liangdabiao/Seedance2-Storyboard-Generator`](https://github.com/liangdabiao/Seedance2-Storyboard-Generator)。

以上都只借方法，未複製任何原文；各專案有各自的授權條款。
