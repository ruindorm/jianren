# 分鏡提示詞規範

> 章節插圖的分鏡怎麼拆、提示詞怎麼寫。**這是製作文件，不上讀者網站**（已加入 `build-site.sh` 的排除清單）。
> 生成參數、成本、壓縮流程見〈[圖片生成](./圖片生成.md)〉，這裡只管「畫什麼」。

分章的分鏡單放在 `docs/分鏡/`，一章一檔，檔名對齊 `src/`。

---

## 0. 這份規範不做什麼

不做影片。GitHub 上找得到的分鏡方法論幾乎都是給 AI 影片用的，時長、運鏡、速度曲線、尾幀銜接那半套一律不採用。
《劍人》的章節插圖是**靜態單格**，能借的只有四件事：鏡頭目的優先、凍結瞬間、景別不重複、資產編號一致性。

也不做全套 storyboard。全書 24 章約 6,500 字，平均一章 270 字，用專業短劇那種一章十幾格的粒度會壓垮內容。
**預設一章一格**，打鬥與轉折章兩格。

## 1. 產出規格

| 項目 | 值 | 理由 |
|---|---|---|
| 比例 | **16:9** | 章節插圖與橫幅，見〈圖片生成〉比例對照 |
| 風格 | **16-bit 像素風** | 與英文版封面同一套視覺，且一眼傳達「這是喜劇」 |
| 品質 | `quality=low` / `resolution=1K` | 固定預設，不要動 |
| 原圖 | `assets/ch/chNN{a,b}-raw.png` | 保留，供之後 image-to-image 改圖 |
| 發布 | `assets/ch/chNN{a,b}.webp` | 壓縮必加 `-Pixel` |

檔名一律 ASCII——GitHub Release 會剝掉非 ASCII 字元。

```powershell
.\tools\gen-image.ps1 -PromptFile prompt.txt -AspectRatio 16:9 -Out assets/ch/ch01a-raw.png
.\tools\compress-image.ps1 -In assets/ch/ch01a-raw.png -Name ch01a -Pixel
```

### 格數配額

| 章型 | 格數 | 適用 |
|---|---|---|
| 對話章 | 1 | 00、02、03、13、14、18、21、22 |
| 場面章 | 1 | 01、04、05、15、16、17 |
| 打鬥／轉折章 | 2 | 06、07、08、09、10、11、12、19、20、23 |

全書約 34 格，以 $0.004/張估，總成本約 **$0.14**。

## 2. 資產編號

跨章一致性靠編號，不靠形容詞。分鏡單裡寫 `C01`，不要重寫一次「穿深色勁裝的年輕劍客」——
重寫就會漂移，漂移到第十章角色就換人了。

### 角色

| 編號 | 角色 | 三個視覺錨點（提案，**待作者確認**） |
|---|---|---|
| C01 | 吾名（男主角・三師兄） | 深色勁裝袖口捲起／腰間一條隨性紅繩／鬆散髮髻加幾綹碎髮 |
| C02 | 佩劍 | 樸素無紋直劍／**劍格一枚方形指示燈**／劍身永遠浮空，不插地 |
| C03 | 大師兄　秦飛羽 | 一絲不苟高馬尾／白底藍緣長袍／永遠站得筆直 |
| C04 | 小師妹 | 淺色短打加長飄帶／腰間香囊／手上常有一方手帕 |
| C05 | 師父（元平・現在） | 灰白長鬚／寬袖灰道袍／慣性動作是撫鬚 |
| C06 | 門僮 | 矮一截的少年／抱著掃帚或藥箱／眼睛總是睜很大 |
| C07 | 龍傲天 | 黑金龍紋長袍／高冠／下巴微抬 |
| C08 | 龍境門使 | 同款黑金制服／面覆／群體同形，不給個人特徵 |
| C09 | 龍境門宗主 | **只給背光輪廓**／雙劍懸浮身前／臉永遠不畫 |
| C10 | 元平（八十年前） | 與 C05 同鼻樑同眉形／黑髮／素白劍服 |
| C11 | 芸兒 | 淡青衣／單邊髮辮／面色偏白 |

二師兄尚未登場，不編號。

> **C02 的指示燈是這套視覺最重要的一項發明。**
> 佩劍是話最多的角色，但它沒有臉。指示燈讓一把劍能演戲：
> 白＝待機、青＝運算中、粉＝害羞或起鬨、紅＝警告、閃爍＝插嘴中。
> 這個約定一旦定下就不能改，它等同於佩劍的表情。

|---|---|---|---|
| S01 | 渡劫大殿外 | S06 | 龍境門主殿 |
| S02 | 前殿（刻龍） | S07 | 本門主殿 |
| S03 | 劍關表空間 | S08 | 劍關重影空間 |
| S04 | 異空間（裡關） | S09 | 風冥洞深處 |
| S05 | 遠方觀戰處 | | |

### 道具

| 編號 | 道具 | 編號 | 道具 |
|---|---|---|---|
| P01 | 天羽劍 | P05 | 光柱 |
| P02 | 傲天劍 | P06 | 龍紋刻痕 |
| P03 | 元劍 | P07 | 手帕 |
| P04 | 劍匣 | P08 | 金丹 |

**鏡像劍要標明。** 劍關的核心設計是「你拿著的是敵人的劍」，畫錯就毀了整個設定。
寫法：`P02鏡像`（龍傲天光柱裡的是本尊 `P02`，秦飛羽手上的是 `P02鏡像`）。

## 3. 分鏡單欄位

每格八欄，**照順序填**。順序本身就是方法：先想清楚這格要幹嘛，才輪到選景別。

| # | 欄位 | 說明 |
|---|---|---|
| 1 | **鏡頭編號** | `SB-08-A`。章號兩位、格序用字母 |
| 2 | **位置** | `置頂` 或 `置底`。決定揭示邊界，見規則五 |
| 3 | **鏡頭目的** | 一句話：讀者必須看到什麼、感受什麼。**先寫這欄** |
| 4 | **揭示邊界** | 這格可以透露到哪裡；本章的哏允不允許出現 |
| 5 | **景別・機位・視線** | |
| 6 | **凍結瞬間** | 運動中的一瞬。禁止「先、再、然後」 |
| 7 | **資產綁定** | C／S／P 編號，加持物、傷勢、光向 |
| 8 | **排除項** | 只寫這格的實際風險 |

底下再接**提示詞正文**（英文）與**生成指令**。

章末補一張**覆蓋表**，把本章每個段落標成四類之一：

| 標記 | 意思 |
|---|---|
| `covered` | 由某一格落實 |
| `intentional_repeat` | 刻意重複，附理由 |
| `omitted_with_reason` | 有理由地不畫 |
| `nonvisual_context` | 純資訊，本來就不需要畫 |

覆蓋表的價值不在「畫了什麼」，在**強迫你面對「這段我為什麼不畫」**。
《劍人》大半是對白，不寫覆蓋表就會不知不覺只畫打鬥。

## 4. 七條硬規則

**一、先目的，後景別。**
鏡頭不是給段落加幾個攝影形容詞。填不出第 3 欄就代表這格不該存在——刪掉。

**二、凍結瞬間，不是流程。**
一格是一瞬。提示詞裡不准出現「先……再……最後」、不准描述表情變化過程、不准描述運鏡。
寫「火花正從接觸點炸開、還在擴散」，不要寫「兩劍相撞後火花四射」。

**三、運動中，不是擺拍。**
劍要劈到一半、拳要正在推進、光要灌到一半。已經完成的死姿態會讓整章插圖看起來像立繪展示。

**四、景別不連號。**
**相鄰三章不得使用同一景別。** 一章一格的節奏下，讀者是連著翻的，
連三張中景群像會讓整本書看起來像同一張圖。分鏡單第 5 欄要能一路掃過去檢查。

**五、邊界順讀——這條是為連載寫的。**
插圖出現在讀者眼前的時間點，決定它能透露多少。

- **置頂格**：只能含本章開頭已經成立的資訊。**不得洩露本章的轉折或笑點。**
- **置底格**：可以是本章的哏，但不得含本章之後才發生的事。

同一格內也適用：凍結瞬間不得提前包含這一瞬之後才發生的認出、鬆手、持物變化。
例：第八章比愛心那一格可以有眾人石化的臉，但**不能有已經降下的光柱與紅光眼**——那是笑點之後才發生的。

**六、資產綁定用編號。**
第 7 欄寫 `C01 + C02（燈：粉）@ S03`。提示詞正文才展開成英文描述，且展開內容必須逐字對應第 2 節的錨點。

**七、排除項只擋當前風險。**
不要寫萬用禁詞長清單。第五章之前不可能出現光柱，那就在第五章之前的格子寫 `no light pillars`；
第五章之後就不用寫了。清單越長，模型越容易忽略整段。

## 5. 文字政策

**預設畫面不含文字。** 像素風的小字必糊，糊掉的假漢字會毀掉整張圖。

例外：**每格至多兩個短英文字，且必須是標題級大字。**
可用於本身就是笑點的英文台詞（第九章 `YOU BITCH`、第十二章 `YOU LOSE`）。
用了就必須在生成後逐字檢查——〈圖片生成〉的實測是大字很穩、小字會糊，但不保證。

中文字一律不畫，包括招式名、匾額、刻在地上的「到此一遊」。第四章那些刻痕畫成**抽象的龍形凹槽**，不要嘗試寫字。

## 6. 提示詞模板

正文用英文。像素風與攝影術語的英文語彙模型理解最穩，中文意圖寫在分鏡單第 3 欄就夠了。

五段加一行排除，順序固定：

```
[STYLE]    鎖定前綴，逐字複製，不要改
[SHOT]     景別、機位、視線、構圖
[SUBJECT]  人物錨定，逐項對應資產表
[ACTION]   凍結瞬間，現在進行式
[SETTING]  場景與光向
Exclude:   排除項
```

### 鎖定前綴（逐字複製）

```
16-bit pixel art, SNES-era JRPG cutscene illustration, hard pixel edges,
no anti-aliasing, limited palette of about 24 colors, dithered gradients,
1px dark outlines on characters, 16:9 composition.
```

這段前綴是全書視覺的唯一保證，**任何一格都不准改動它**。要調整風格就整本一起改，改完全部重生。

### 動作章加寫的五件事

打鬥格必須看得出這五件事，缺一張圖就會變成「兩個人在發光」：

1. **誰打誰、命中哪**——最高優先。看不懂就重寫
2. **空間幾何**——兩人相對位置、誰在前誰在後、光柱在哪邊
3. **重量感**——反作用力、衣袂鼓盪、重心崩潰
4. **層次**——地面／中段／騰空至少兩層，前／中／背景至少兩層
5. **代價**——破損、喘息、血跡以外的損傷痕跡

## 7. 自檢清單

生成前逐條過，任何一條不過就別送出去（一張 $0.004，但重畫的時間不只 $0.004）：

- [ ] 第 3 欄鏡頭目的填得出來，而且不是「呈現本章劇情」這種廢話
- [ ] 凍結瞬間裡沒有「先／再／然後」，沒有表情變化過程
- [ ] 置頂格沒有洩露本章轉折
- [ ] 凍結瞬間沒有提前包含這一瞬之後才發生的事
- [ ] 與前兩章的景別不同
- [ ] 人物描述逐項對應資產表錨點，沒有臨時發明的特徵
- [ ] 鏡像劍標對了——誰手上拿的是誰的劍
- [ ] 排除項只有本格的實際風險，沒有萬用禁詞
- [ ] 畫面文字 ≤ 2 個短英文字，或完全沒有
- [ ] 覆蓋表填完，`omitted_with_reason` 都寫了理由

生成後：

- [ ] 大字逐字檢查
- [ ] 壓縮加了 `-Pixel`

## 8. 已知地雷

**佩劍不能插在地上。** 它是浮空的。第五章之後光柱裡插地的是本尊劍，那是另一回事——
畫錯會讓讀者以為佩劍下線了。

**「眼露紅光」只在意識被鎖進劍裡的時候。** 表空間的肉身才有紅光眼。
異空間（S04）裡是意識體，不畫紅光。這兩個空間的區別是全書最容易畫錯的地方。

**遠方觀戰處（S05）與表空間（S03）不同框。** 師父與門僮看得到劍關，但他們在遠處。
同框會讓讀者以為師父就站在旁邊沒出手。

**倒地的大師兄不能消失。** 第七章倒地、第九章才醒。中間幾章的群像格裡他必須還躺著。

**八十年前的段落（15–23 章）不要換風格。** 想用褪色或單色調來區分是很自然的念頭，
但那會破壞「重影是即時投影、不是回憶」的設定。改用**冷色偏移**（整體偏青灰）就夠了。
