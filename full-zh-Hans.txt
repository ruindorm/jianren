# 楔子

**男主角**：嘿，man，谁是世界上最贱的人？

**佩剑**：主人，说到贱，您绝非浪得虚名。但世界上最贱的不是您，另有其人。

**男主角**：妈的，听你这么说让我很不爽！你是不是以为我会问你他是谁？

**佩剑**：不会。根据主人您的尿性，您偏偏就不问我，这样就可以打脸观众。

**男主角**：他是谁？

**佩剑**：……好的。搜索需要一点时间，主人您需要先配置 git 环境吗？确保搜索结果可回滚。

**男主角**：滚你妈！你是不是还不清楚我的真正实力？

**佩剑**：这个问题要加入搜索联集吗？

**男主角**：你这把剑真的很贱！

**佩剑**：主人，我们的作品叫做《剑人》，就是我跟你的搭配，对吗，主人？

**男主角**：…………

# 第一章　渡劫大殿外

**大师兄**：哟！这不是师弟吗？你的病越来越严重了！

**男主角**：你才有病！你全家都有病！

**大师兄**：胡言乱语、经常自言自语——我早告诉师父，你早已走火入魔！

**男主角**：讲个话也碍着你了吗？

**大师兄**：师弟，别怪我无礼。（剑指起）师父说过，治疗走火入魔，就是要打通阻塞的经脉……

**男主角**：（冷笑）干架还要找理由？

**大师兄**：（凝指）看剑！

金属撞击，火花四起，大师兄的剑被一道无形剑气挡下。

**大师兄**：啊！师父，您怎么来了？

**师父**：（收回剑指）渡劫大殿，不是切磋的地方。

**小师妹**：（跑到男主角身边）对嘛～这边气场敏感，引动天雷谁要负责呢？对吗，宝宝？

**男主角**：（得意）That's right！师妹你今天好香啊～

**小师妹**：你上次教的调香配方，真的很让人家喜欢……

**大师兄**：（气炸）疯言疯语！师父您看，师弟言词已经杂乱无章、让人无法理解，徒儿只是想疏通他的经脉！

**男主角**：疏通经脉不是用内力吗？你刚刚用剑了，贱招～

**佩剑**：主人，您这句台词不够帅。您要说——「大师兄用剑疏通经脉，想必自认修为高过师父了呢？」

**男主角**：高你妈啦！不要挑拨我跟师父的感情！

**大师兄**：你看你看！师父！师弟的症状越来越严重了啊！

# 第二章　剑关之约

**师父**：为师确实不懂「辣死赖」是什么意思。但切记，修道之人不可执著名义。

**小师妹**：师父～「辣死赖」就是「没错」的意思！就像师父您刚刚说的教诲，真的是 that's right！

**男主角**：师妹的语言能力真棒！

**大师兄**：废话少说！师弟，要不是看在你走火入魔的份上，你早该跟我进行剑关考验了。

**佩剑**：主人，快点抖出来——是大师兄自己要等师父教完《万仙诀》才有把握打败你，才不跟你进行剑关考验的。

**男主角**：你懂个屁！

**大师兄**：（内心：他是在骂我吗？）

**小师妹**：（歪头）（宝宝在生气吗……）

**师父**：（抚须沉思）（这孩子……莫非是在点醒为师？）

**佩剑**：主人，要接受第二套方案吗？

# 第三章　闯关者

**门僮**：（慌张）不好了！师父、师姐、两位师兄——化境宗门的龙境门带人要来闯剑关！

**大师兄**：慌什么？当我们这边是什么地方？师父您回殿休息，这种角色我跟师妹就可以摆平了！

**师父**：不同宗门的剑关，不能随意挑战。徒儿，你带师妹、师弟去了解情况，切记以和为贵，莫要意气用事！

**小师妹**：师兄～我们走吧～（拉起男主角的手）

**大师兄**：（看着男主角跟小师妹）哼！

**佩剑**：主人，第二套方案？先跟您说一下方案摘要——

**男主角**：闭嘴啦！没看到我在忙？喔，小师妹不是说妳，哈哈，好，我们走慢一点……

**师父**：（看着众人背影点头，手摸着胡子）

**门僮**：师父，弟子扶您回殿……

# 第四章　前殿刻龙

**男主角**：哇靠北！搞什么啊？

**小师妹**：你们龙境门不是要来挑战剑关吗？怎么把我门前殿搞成这样？

**大师兄**：在我们的前殿地上跟梁柱刻龙？

**龙境门使**：哈哈，到此一游，留下一些痕迹，让你们欣赏不好吗？

**大师兄**：狂妄！我看你们不是来挑战剑关，是来耀武扬威的！

**龙境门使**：我们全都要！

**男主角**：贱人！喂！上场啊！

**佩剑**：主人，您在调用我吗？我不叫「喂」，您要修改启动指令吗？

**龙境门使**：看来你们这门派容易走火入魔啊！大敌当前，还在自言自语？

**小师妹**：两位师兄不要冲动，我来。（走向前）

**小师妹**：听闻龙境门的龙剑不但杀伤力强大，而且姿态优美。但我看你们刻的龙，像米虫。

**龙境门使**：说什么！

**小师妹**：别急啊。不同宗门要挑战剑关，需要人剑分离质押、剑招明示，输家要在自己的剑关立下败战耻辱——所以通常不同宗门，不太随便挑战对方的剑关……

**龙境门使**：哼！规则我们比妳还清楚。今天来，就是要在你门的剑关，立下你门的败战耻辱！

**佩剑**：主人，这时候您可以出来解释更多，观众比较容易听懂。

**男主角**：你信不信我把你当废铁卖？出主意很快，刚叫你上场装死？

**佩剑**：对方还没同意质押，还不能上场偷跑。而且您没有启动指——

**男主角**：你那个启动，非要现在吗？

**佩剑**：虽然羞耻了一点，但这是主人您自己设置的。

**男主角**：唉……

# 第五章　剑关打开

**龙傲天**：婆婆妈妈、畏首畏尾——没一个能打的吗？

一名帅气男子从门使后方走出，龙境门使让开一条路。

**男主角**：唉唷，等手下讲完自己才走出来，很爱装逼。

**佩剑**：主人，您遇到装逼对手了。

**男主角**：（瞪了佩剑一眼）……

**小师妹**：（对着龙傲天说）就是嘛。你是谁啊？

**龙傲天**：开了剑关，不就知道我是谁了吗？没人敢一战吗？也行吧！（示意手下，手下递上一把普通剑）

**龙傲天**：练练书法……（轻佻地用剑在前殿地上开始刻字）

**大师兄**：住手！欺人太甚！你，要亲自应战吗？

**龙傲天**：没错。能接受我的剑关挑战，是你的荣幸。

**大师兄**：少侮辱人！本宗门剑关——吾：秦飞羽，剑：天羽剑，打开剑关！

**小师妹**：大师兄！

地板震动，狂风大作，天空出现了诡异的次元空间，所有人的思考与动作被强制缓速。

大师兄周围出现了一股斥力，并有两条光柱贯穿天际线，一条光柱里面是天羽剑，正笔直地插在地上。

大师兄眼露红光，意识已经被锁在天羽剑中。

**龙境门使**：来吧！（两个人擡上一个剑匣）吾：龙傲天，剑：傲天剑，进入剑关！

剑匣破碎，傲天剑被吸入另外一条光柱，并且笔直插在地上，龙傲天意识被锁在傲天剑中。

**众人**：（屏息以待）

光柱似乎在扫描、读取两把剑。异次元空间光线不断变化，随即，向着两人面前射出两把剑——

龙傲天面前的是天羽剑的镜像，龙傲天毫无犹豫地拔起来，指向秦飞羽。

秦飞羽面前的是傲天剑的镜像，一个剑指，也把剑转向了龙傲天。

真正的剑关决战，即将开始。

# 第六章　天羽击

光柱里的天羽剑微微震动，与秦飞羽眼中的红光呼应。手持镜像傲天剑，第一剑——天羽击，目标：远方光柱里的傲天剑。

龙傲天拿起镜像天羽剑挡住，但巨大冲击力逼得他后退数十步……惊人的震波，让异度空间响起刺耳的嗡嗡声。

**小师妹**：大师兄又进步了！本能反应的起手式！

**佩剑**：主人！这招看起来，像是要对付您练的！

**男主角**：搔痒用的吧。

**佩剑**：主人，请勿轻敌。

**男主角**：讲得好像你上场就稳赢。

**佩剑**：主人，根据我过往的胜率分析，您……

**男主角**：（装没听见）小师妹，要坐过来一点吗？这边视角比较好，不会被剑气扫到喔～

**佩剑**：……（进入观战模式）

龙傲天眼露凶光，招招刺向秦飞羽要害——看来，是打算先杀了秦飞羽，再来破坏天羽剑。

> **〔远方〕**

**门僮**：哇！好惊人的景观，我第一次看到剑关打开！

**师父**：嗯……剑关是无意识的本能反应战斗，只有剑本身，代替本人操控对手的剑。

**门僮**：什么？那大师兄去哪里了？

**师父**：你的大师兄，意识被锁在天羽剑里面，双方都被质押在场上。

**门僮**：这不是很危险吗？万一对方人多势众，进来拔剑呢？

**师父**：哈哈，对方主将也一样被锁在剑里啊！你看他们，紧张得不敢轻举妄动。

**门僮**：原来如此！那么大师兄现在是睡着了吗？

**师父**：正好相反。你的大师兄，意识跟对方正在异空间里面激战着呢！


> **〔异空间〕**

秦飞羽摆出应战架势，龙傲天轻蔑地站着。

**龙傲天**：秦飞羽，我有一个提议。

**秦飞羽**：你又有什么阴谋诡计？

**龙傲天**：我们在此休兵，让我们的剑决定胜负，如何？

**秦飞羽**：（保持警戒）剑关胜负判定本来就在剑决，但这里……

**龙傲天**：你对自己的剑很没信心啊！

**秦飞羽**：哼！好，我就看你的剑如何打败我的剑！

**龙傲天**：（冷笑）（中计了吧……）


> **〔远方〕**

**门僮**：师父，里空间我们看不到，到底怎么分出胜负呢？

**师父**：只要摧毁对手光柱里面的剑，或者把剑打出光柱外面，就算赢了。

**师父**：小徒啊……这对你是难得的经验，好好看……趁此良机啊……

**门僮**：是！师父！

# 第七章　天龙斩

> **〔表空间〕**

**小师妹**：啊——！

眼见大师兄想摆脱龙傲天纠缠，持续往傲天剑的光柱移动，龙傲天似乎正等着大师兄这一步。

大师兄使出一招双羽击，同时向前与向后射出两道剑气：一道阻止龙傲天的纠缠，一道射向傲天剑——

傲天剑受到剑气冲击，被击出半吋。只要再一击，就可以把剑打出光柱，但……

「天龙斩——！」

一道霸气无比的剑气，自大师兄后方袭来。因大师兄急着把傲天剑打出光柱，直接受创，被击飞数十米，倒地不起……

龙傲天眼看得手，近乎挑衅地慢慢走向天羽剑光柱，刻意用不会武功的动作，把天羽剑打出光柱。

**龙境门使**：哈哈，不堪一击！你们宗门，简直就是笑话！

**小师妹**：大师兄……

异度空间开始变异，就在光柱要回收的时候——

**男主角**：（大喝一声）给我差不多一点！吾名——

# 第八章　吾剑启动

**男主角**：吾名：吾名！剑：剑！接替入关！

**佩剑**：呃，主人，少了那个……

**小师妹**：师兄！小心啊！

**龙傲天**：？？？

**龙境门使**：？？？？

**倒地的大师兄**：呃……？？？？

**男主角**：（胀红着脸，对着佩剑比了爱心）吾剑启动！

**众人**：…………

异度空间光柱再次降下，一边是傲天剑，一边是……嗯，男主角的剑。

**吾名**：……（眼露红光），拿起了傲天剑的镜像。

龙傲天手上的天羽剑镜像被回收，他拿起了新的镜像剑——男主角的佩剑。

**吾名**：御剑阵！

吾名周围弥漫了剑气，闪耀着诡异的光芒……似乎在观察、读取龙傲天的所有行为。

**龙傲天**：（暂时僵住）

**众人**：……暂时说不出话。

**远方的师父**：嗯……（手摸着胡须）

# 第九章　You Bitch

> **〔表空间〕**

**吾名—佩剑版**：You bitch！

**众人**：……？？？？？

**龙傲天**：（眼露凶光，手握镜像剑）

**吾名—佩剑版**：呵呵……（剑指起）一道剑气射向龙傲天脸上。


> **〔远方〕**

**门僮**：师父，「优闭取」是什么意思？你不是说，意识会被锁进剑里面吗？为什么三师兄能说话？

**师父**：这……为师也不太明白。剑御剑，会反映剑主人平常的潜意识与身体动作……也许你要自己问师兄。

**门僮**：我以后也要这么酷！

**师父**：徒儿，你说什么？

**门僮**：这是三师兄教我的，他说：be……酷。

**师父**：（摸摸门僮的头）哈哈哈……


> **〔表空间〕**

剑决持续激烈进行着。

龙傲天拿起佩剑随手挡掉剑气。而后方的傲天剑，在刚刚吾名接关的时候，早已恢复原本插入地上的深度（战局初始设置）。

龙傲天握紧了佩剑，往吾名—佩剑版与佩剑光柱扫去。一开始气劲十足，后来消融在剑阵里面。

**小师妹**：大师兄……你还好吗？

**大师兄**：咳……没事，刚刚稍微晕了过去……天羽剑退出剑关，我意识也回来了。

大师兄随即盘坐调息，并看着战场变化。

光柱开始变色——剑关提醒：二阶段剑关要来了。

龙傲天屡次不得手，开始加快了进攻速度。

**吾名**：现在测试防御行为。

说完，剑阵消失，然后从傲天剑光柱附近重新出现。

**龙傲天**：（大惊失色）

# 第十章　异空间・里交手

> **〔异空间〕**

**龙傲天意识（以下简称「龙傲天」）**：哼！自言自语的神经病！

**吾名意识（以下简称「吾名」）**：我看你是不懂喔！现在佩剑在跟你的剑打，我要找人聊天也没办法！

**龙傲天**：看来你是想尝尝你大师兄的苦头？

**吾名**：我看你是不懂我真正实力喔！

**吾名**：（侧身闪＋擒拿手）没人教过你们，到别人家不要乱涂鸦吗？（反身一掌，但打在对方屁股上）

**龙傲天**：（恼羞成怒）【崩山劲】——力道奇大无比，吾名被震退两三步。

**吾名**：我看你情绪管理也有问题喔！还要热身吗？


> **〔剑关内〕**

**小师妹**：大师兄，护罩变化很快！

**大师兄**：嗯……看来里头交手激烈。里交手的输赢，会决定光柱护罩强度——只靠剑是不行的。

**小师妹**：大师兄，刚刚龙傲天是怎么打掉你的剑的？

**大师兄**：他跟我谈判，让剑决输赢，但突然偷袭我……

**小师妹**：真是贱人！

**龙境门使**：（彼此交换眼神，正在计划着什么……）

**吾名—佩剑版**：剑关二阶段，倒数十秒……

**龙傲天—傲天剑版**：（看着后方剑阵大惊失色，随即快速返手握剑，正在读取吾名佩剑的剑招……）

**吾名—佩剑版**：Open book 给你考试，被当掉别怪我。（御剑阵 2 蓄势待发，准备在剑关二阶段瞬间施展）

# 第十一章　聚龙临界

**龙傲天**：无礼后辈——见识真正的力量吧！

前殿的龙纹刻痕忽然发光，串联成一条龙形，往异空间移动。

**大师兄**：【聚龙临界】！

**小师妹**：发生什么事？

**门僮**：师父，您不出手吗？

**师父**：相信你的师兄师姐……

**吾名—剑版**：（看到龙形进入异空间，反应机制启动）意外，冒烟——第二套方案，备援运行。

**龙傲天—剑版**：【天龙变形斩】！

## 几件关于著作权的事实（作者自己也该知道）

### 1. 著作权是自动产生的，不需要登记

我国著作权法采「创作保护主义」——作品完成的那一刻，著作权就成立了。
台湾自 1998 年起已**废止著作权登记制度**，智能财产局不办理著作权注册。
所以不存在「去登记才有版权」这回事，也不要相信任何说能帮你「登记著作权」的收费服务。

### 2. 著作人格权永远是你的，不能让与

著作权分两块：

| | 内容 | 能不能给别人 |
|---|---|---|
| **著作人格权** | 公开发表权、姓名表示权、禁止不当改变（同一性保持权） | **不得让与、不得继承** |
| **著作财产权** | 重制、公开传输、改作、散布、出租等 | 可授权，也可让与 |

意思是：就算将来把财产权整包卖给出版社，「这是谁写的」这件事，法律上永远是你。
别人把你的作品改得乱七八糟并挂你的名，你仍可主张人格权受侵害。

### 3. 著作权保护「表达」，不保护「点子」

这是最容易误解的一点，也是必须诚实讲的：

**受保护的**：你写下的具体文本、对白、段落安排、具体到足以识别的角色塑造。
别人整段拷贝、换几个词重贴、翻译后发布——都是侵权。

**不受保护的**：「一把会吐槽的 AI 佩剑」这个概念、「剑关」这种决斗制度的抽象构想、
「主角被误会走火入魔」这种桥段。别人用同样的点子，自己从头写一部完全不同的作品，
法律上不构成侵权。

对创意本身，实务上真正有效的保护是三件事：

1. **先发布、留下时间纪录**——谁在先，一目了然
2. **把设置做深做厚**——抽象点子挡不住，但「剑关表关里关双层判定 + 二阶段天雷缝隙 +
   剑匣强制中止」这种具体到骨架的体系，抄的人只要照搬就是抄表达，不照搬就写不出同样的东西
3. **累积辨识度**——大家先在你这里看过，后来者反而像模仿

### 4. 书名不受著作权保护

「剑人」这两个字本身不是著作。如果之后要当成 IP 经营（周边、影视、系列作），
真正能挡别人用同名的是**商标**，不是著作权。可向经济部智能财产局申请，
相关类别大致是第 16 类（书籍印刷品）与第 41 类（娱乐、在线出版）。
不急，但如果哪天作品红了，这件事要趁早做。

## 这个仓库本身就是证据

Git 的每一个 commit 都记录了**内容、时间、作者**，且无法在不留痕迹的情况下窜改历史。
GitHub 的公开推送纪录则提供了第三方的时间佐证。

换句话说：**「这段文本在某年某月某日就已经存在，且出自我手」——这件事本仓库已经自带证明。**
这比多数作者的处境好很多。

想再加强的话，可以做这几件事（依成本由低到高）：

- **打 tag 发 Release**——为每个阶段的完整版本留一个不可变的快照点
- **GPG 签章 commit**——commit 上会显示 Verified，证明确实出自你的密钥
- **公证**——对法院所属民间公证人办理著作物认证，取得公证书（有费用，证据力最强）
- **美国著作权局登记**——只有打算在美国提告求偿时才需要，一般不必

## 发布到其他平台之前，请先做这件事

**看清楚平台的服务条款。** 有些平台（尤其是网文站、部分 MCN 合作）的条款会要求：

- 取得作品的**独家授权**，或
- 取得**可转授权、可改作的广泛授权**，或
- 主张平台对内容有**优先签约权**

这类条款可能与本仓库的 CC 授权冲突，也可能让你在不知情的状况下交出改编权。
签之前一定要看第一段和「授权」那一节。

# 世界观：剑关规则

> 正文中已经明说的规则，集中在这里，方便写后续章节时对照。
> **只记录原文写出来的内容。** 推论不写进这里。

## 剑关打开时

1. 地板震动、狂风大作，天空裂出**异次元空间**
2. 在场所有人的思考与动作被**强制缓速**
3. 两条**光柱**贯穿天际线，各自封入一把本尊剑，笔直插在地上
4. 双方意识被**锁进自己的剑**中，肉身留在原地，眼露红光——师父称之为「被质押在场上」

## 声明格式

> 吾：〈姓名〉，剑：〈剑名〉，**打开剑关**！（挑战方为「进入剑关」）

男主角的版本是「吾名：吾名！剑：剑！**接替入关**！」——并且需要对佩剑比爱心才会启动。

## 交错的内核设计

光柱扫描读取两把剑后，会向两人射出**对方那把剑的镜像**。

也就是说：**你拿着的是敌人的剑，操控它去攻击敌人自己的本体剑。**

## 胜负判定

师父的说法：摧毁对手光柱里面的剑，或者把剑打出光柱外面，就算赢了。

剑受到剑气冲击会被逐吋击出（傲天剑曾被击出半吋）；接关时会重置回初始深度。

## 表关与里关

| | 表空间（剑关内） | 里空间（异空间） |
|---|---|---|
| 谁在打 | 两把镜像剑 | 两人的意识 |
| 观众看得到 | 看得到 | 看不到 |
| 作用 | 直接决定胜负 | 输赢决定**光柱护罩强度** |

大师兄的结论：**只靠剑是不行的。**

里关可以谈判——龙傲天正是用「休兵、让剑决胜负」的提议骗过秦飞羽，然后偷袭。

## 二阶段：天雷降世

光柱开始变色即为预告。大师兄的说法：进入二阶段的瞬间，**表、里两关会出现暂时的缝隙**。

缝隙可以被外力利用：龙境门事先刻在前殿的龙纹，就是在这一刻聚成龙形、穿过缝隙贯入龙傲天体内（聚龙临界）。

天雷本身也能被引导——男主角的剑分形直接把天雷连通到对手光柱，形成无法防御的打击。

## 挑战的代价

小师妹讲出来的规则：

- **人剑分离质押**
- **剑招明示**
- 输家要在自己的剑关**立下败战耻辱**

所以通常不同宗门不太随便挑战对方的剑关。

## 强制中止

**剑匣**可以在结算完成前吸回本尊剑，强制中止剑关，双方意识立即回归。

师父见到时的反应：「果然出现了……没想到那个剑匣还在。」
