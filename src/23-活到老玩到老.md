# 第二十三章　活到老，玩到老

〔閃回〕


〔劍關三階〕

**芸兒**：平，沒事吧？

**元平**：小意思！我們繼續……


〔劍關四階〕

**元平**：芸，等會按照計畫走位！

**芸兒**：平……這關卡越來越兇險……也許我們不該來……


〔劍關五階〕

**芸兒**：平……你受傷了……我們退出好不好？我本來就活不久了。

**元平**：我沒事！誰說妳活不久？我們會活到老，玩到老……


〔劍關六階〕

**芸兒**：平……如果我死了，答應我馬上退出！

**元平**：說什麼傻話？妳不會死，我也不會。劍關七階要來了——當心！


〔劍關七階〕

**芸兒**：平……我不值得你這樣做。

**元平**：（喘息）（開心微笑）我們快到了！劍關八階要開了……

**芸兒**：唉……


〔劍關八階〕

**芸兒**：…………

**元平**：（握住芸兒的手）…………


（待續……）
