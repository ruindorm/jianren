# 第十三章　樣本

**龍傲天**：宗主，任務成功了。

**宗主**：很好，打開吧。

**龍境門使**：（抬上了劍匣並打開）

**宗主**：（以劍指運起傲天劍跟另外一把寶劍）喝！

雙劍在空中互擊，宗主閉上眼睛。

**宗主**：妙啊！這把佩劍……藏著某種莫名的靈動之力……

**龍傲天**：宗主英明！此次挑戰劍關，弟子已撐到天雷二階，盡量為宗主爭取更多樣本……

**宗主**：很好。她呢？

**龍傲天**：嗯，大小姐也很好，目前與那個奇怪的劍者互動親密。

（兩把劍互擊完畢，歸於寂靜）

**宗主**：（滿意地收回內力）哈哈哈……不會太久的……

**龍傲天、龍境門使**：…………（維持敬畏姿勢不動）


（待續……）
