# 第十六章　背對背

〔重影之中〕

帥氣劍客與美女劍客背對背而立。周圍產生異樣的光線，看得出來，兩個人非常緊張。

**帥氣劍客**：芸，調息，別怕，我在！

**美女劍客**：知道！我也在！

劍關九階降臨的瞬間——美女劍客手中的劍，發出詭異光芒。

美女劍客大驚失色，雙手緊緊握住劍，冷汗直流，驚恐萬分——

**美女劍客**：啊！危險！平，你快走！

**帥氣劍客**：什麼？呃……

美女劍客一劍刺向帥氣劍客——
